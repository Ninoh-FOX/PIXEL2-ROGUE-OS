
PCSX Core - All-in-One Emulator Configuration
Configure the all-in-one emulator with the PXCS core.
Notes:
The emulator defaults to enabling 3D HD resolution. For untested games that lag with 3D HD enabled, bring up the menu, go to Core Options, and disable enhanced resolution (slow).
Special BIOS usage method: Rename the ROM file to match the BIOS file name, then place both in the ROM folder.
How to use cheat codes:
Open the menu and select Cheats → Load Cheat File (Overwrite) → Choose the cheat file for the current game.
Finally, enable the desired cheat codes and click Apply Changes.

The universal shortcut key functions are as follows:
Menu: Right side menu key
Exit: SE+ST pressed twice
Quick save: SE+R1 Quick load: SE+L1 Acceleration: SE+R2
Brightness: SE+Arrow keys up/down
Volume: Left side volume/SE+key up/down
Auto-fire: Hold R2 down without releasing, and then press the key you want to turn on auto-fire,
      e.g.2 held down   A is on A key auto-fire, press B is B auto-fire, and to turn off auto-fire just hold R2 the activated autofire key again.
